- `09 Worker threads`
- `10 Streams & backpressure`
- `11 Graceful shutdown`
- `12 Logging & request IDs`
- `13 Testing`
- `14 Load testing`

The current work has been preserved under `01 Raw HTTP server/nodejs/` so the existing files and setup stay intact while the repo matches the course layout.
